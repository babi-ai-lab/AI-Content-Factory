# وضعیت تحویل مهاجرت ParsPack

## خلاصه
شاخه `parspack-php-migration` اکنون یک هسته اولیه PHP 8.1+ و MySQL به همراه APIهای پایه احراز هویت، برند، محتوا، تاریخچه نسخه و کمپین دارد. این شاخه هنوز محصول کامل یا نسخه قابل انتشار Production نیست.

## پیاده‌سازی‌شده
- معماری مهاجرت به PHP اختصاصی و MySQL محلی
- migration اولیه جداول کاربران، نشست‌ها، توکن‌ها، برندها، محتوا، نسخه‌ها، کمپین‌ها، سنجه‌ها، رسانه، مصرف، rate limit و تنظیمات
- bootstrap و config نمونه PHP؛ اتصال PDO با prepared statements
- نشست HttpOnly، Secure روی HTTPS، SameSite، strict mode و عدم پذیرش session id از URL
- CSRF مبتنی بر توکن تصادفی و hash_equals
- پایه ورود با password_hash/password_verify، بازتولید session id و ثبت/اعتبارسنجی نشست در MySQL
- خروج و حذف نشست
- محدودسازی اتمیک تلاش ورود بر اساس IP
- API دریافت CSRF، login، logout و me
- API برندها: فهرست، ایجاد، ویرایش و حذف؛ سقف ۱۰ برند برای هر کاربر
- API محتوا: فهرست، ایجاد، خواندن، ویرایش، حذف نرم و تاریخچه نسخه؛ کنترل مالکیت کاربر
- API پایه کمپین: فهرست، ایجاد و حذف
- workflow بررسی syntax فایل‌های PHP با PHP 8.1
- مستندات API، نصب و handoff

## موارد باقی‌مانده
- بازنویسی کامل رابط کاربری Next.js/React به HTML/CSS/JavaScript
- تطبیق کامل schema با تمام migrationهای واقعی Supabase و تست mapping
- ثبت‌نام عمومی امن، تأیید ایمیل، بازیابی رمز و ابطال همه نشست‌ها
- rate limit عمومی برای APIها، audit log و تست‌های خودکار/امنیتی
- API تولید متن/تصویر و اتصال به پردازشگر AI با انتخاب صریح مالک
- مدیریت فایل و انتقال Storage به مسیر خصوصی خارج از document root
- انتقال و تطبیق داده‌های واقعی، شمارش رکورد و checksum فایل‌ها
- تکمیل مدیریت کمپین، تقویم شمسی، سنجه‌ها، گزارش‌ها و پنل مدیریت
- کیف پول، اشتراک و درگاه پرداخت ریالی
- اجرای موفق CI، تست روی PHP/MySQL واقعی ParsPack، staging، backup/restore و rollback
- نصب روی `app.eltbabak.ir` و تغییر ترافیک پس از تأیید کامل

## محدودیت AI
هاست اشتراکی معمولی برای اجرای inference مدل‌های بزرگ مناسب فرض نمی‌شود. هسته برنامه و داده‌ها می‌توانند داخلی باشند؛ تولید هوشمند یا نیازمند پردازشگر خارجی مورد تأیید مالک است یا باید به تولید قالبی/قاعده‌محور محدود شود. هیچ provider یا هزینه‌ای بدون تصمیم صریح مالک فعال نمی‌شود.

## مواردی که هنوز روی هاست بررسی نشده‌اند
- نسخه واقعی PHP و MySQL/MariaDB
- افزونه‌های PDO، pdo_mysql، mbstring، fileinfo، openssl و curl
- امکان Cron و محدودیت‌های حافظه/زمان اجرا
- مسیر document root زیردامنه و امکان ایجاد دیتابیس جدا
- دسترسی نوشتن به مسیر storage خصوصی
