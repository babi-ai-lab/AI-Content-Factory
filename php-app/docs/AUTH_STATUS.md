# وضعیت پیاده‌سازی احراز هویت

در این مرحله فقط سرویس پایه PHP اضافه شده است:
- ثبت حساب با `password_hash()` و وضعیت اولیه `pending`
- ورود فقط برای حساب `active`
- `password_verify()` و پیام خطای یکسان برای ایمیل ناشناخته/رمز نادرست
- بازتولید شناسه نشست پس از ورود
- ثبت hash شناسه نشست در MySQL و حذف آن هنگام خروج
- توکن CSRF مبتنی بر `random_bytes()` و مقایسه امن با `hash_equals()`

## پیش از فعال‌سازی عمومی هنوز لازم است
1. مسیرهای HTTP ثبت‌نام، ورود، خروج و کاربر جاری با اعتبارسنجی ورودی و پاسخ‌های کنترل‌شده.
2. محدودسازی تلاش ورود و ثبت‌نام به‌صورت اتمیک و پایدار.
3. ارسال و تأیید ایمیل و توکن‌های یک‌بارمصرف با انقضا.
4. بازیابی رمز عبور، چرخش نشست‌ها، ابطال همه نشست‌ها و سیاست انقضا/عدم فعالیت.
5. تست خودکار، تست CSRF و تست دسترسی مالکیت‌محور.
6. ثبت audit events و بررسی حذف حساب/خروجی داده.
7. تنظیم SMTP و تأیید وجود افزونه‌های PHP موردنیاز روی هاست.

مسیر راه‌اندازی اولیه برای ساخت تنها اولین حساب فعال اضافه شده است؛ ثبت‌نام عمومی، تأیید ایمیل و بازیابی رمز هنوز پیاده‌سازی نشده‌اند. این سامانه هنوز برای Production کامل آماده نیست. از آن برای جایگزینی Supabase Auth تا پایان تست مهاجرت استفاده نکنید.
