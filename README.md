# AI Content Factory — MVP 0.1

وب‌اپلیکیشن فارسی برای تولید بسته محتوایی فروشگاه‌های پوشاک و اکسسوری.

## امکانات فعلی
- فرم اطلاعات محصول
- تولید کپشن فروش، سناریوی ریلز، ۵ استوری و متن تبلیغاتی
- رابط فارسی و راست‌به‌چپ
- خروجی نمایشی بدون نیاز به API Key
- امکان اتصال به API سازگار با OpenAI از طریق متغیرهای محیطی
- کپی خروجی

## پیش‌نیاز
- Node.js نسخه 18.17 یا جدیدتر
- npm

## اجرا در کامپیوتر

```bash
npm install
npm run dev
```

سپس مرورگر را در آدرس زیر باز کن:

```text
http://localhost:3000
```

## فعال‌کردن تولید واقعی با AI

فایل `.env.example` را به `.env.local` کپی کن و مقادیر را وارد کن:

```env
AI_API_KEY=your_api_key
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
```

نکته: اگر ارائه‌دهنده دیگری با API سازگار با OpenAI استفاده می‌کنی، `AI_BASE_URL` و `AI_MODEL` را مطابق مستندات همان ارائه‌دهنده تغییر بده. کلید API را هرگز در فایل‌های سمت مرورگر یا GitHub قرار نده.

بدون این تنظیمات، برنامه با داده‌های نمونه و الگوهای داخلی اجرا می‌شود؛ این حالت، تولید واقعی توسط مدل زبانی نیست.

## ساختار پروژه

```text
app/
  api/generate/route.ts   # API سمت سرور برای تولید محتوا
  globals.css             # طراحی و واکنش‌گرایی
  layout.tsx              # تنظیم زبان فارسی و RTL
  page.tsx                # فرم محصول و نمایش خروجی
```

## محدودیت‌های نسخه 0.1
- ورود و ثبت‌نام ندارد.
- تاریخچه فقط در حافظه همان صفحه نگهداری می‌شود و با رفرش پاک می‌شود.
- پرداخت و اشتراک ندارد.
- تولید تصویر و ویدئو ندارد.
- خروجی AI ممکن است نیازمند بازبینی انسانی باشد.
- قبل از انتشار عمومی، rate limit، احراز هویت، ذخیره‌سازی امن، ثبت هزینه و کنترل سوءاستفاده اضافه شود.

## مرحله بعد
1. تست با ۵ تا ۱۰ فروشنده واقعی پوشاک.
2. جمع‌آوری نمونه خروجی‌های خوب و بد.
3. اصلاح prompt و قالب کمپین.
4. سپس افزودن ورود کاربر و تاریخچه پایدار.
