# AI Content Factory

وب‌اپلیکیشن فارسی برای تولید و مدیریت محتوای بازاریابی و برنامه‌ریزی کمپین‌های کسب‌وکارها.

نسخه آنلاین: https://app.eltbabak.ir/

## قابلیت‌های پیاده‌سازی‌شده

- ورود و ثبت‌نام کاربران با Supabase Auth، تأیید ایمیل، بازیابی رمز عبور و درخواست حذف کامل حساب
- اطلاع‌رسانی شفاف، ثبت و امکان لغو تأیید پیش از ارسال داده کسب‌وکار به پردازشگر محتوای متصل
- تولید کپشن، سناریوی ریلز، مجموعه استوری و متن تبلیغاتی با موتور پردازش محتوای متصل
- تولید تصویر تبلیغاتی و کاروسل پنج‌اسلایدی با مدل تصویر متصل در استودیوی رسانه؛ ذخیره و مدیریت در کتابخانه خصوصی Supabase Storage، لینک موقت امضاشده، ویرایش متن فارسی و خروجی PNG هر اسلاید، و سهمیه اتمیک ۵ تصویر در ساعت
- پشتیبانی از ۹ نوع کسب‌وکار و ۱۰ قالب تخصصی تولید محتوا
- انتخاب مدل جایگزین در خطاهای موقت ارائه‌دهنده
- احراز هویت API با توکن Supabase، اعتبارسنجی ورودی و محدودیت بدنه ۱۶ کیلوبایتی
- محدودسازی پایدار و اتمیک درخواست تولید در PostgreSQL (۸ درخواست در هر ۱۰ دقیقه)
- ذخیره تاریخچه محتوا با جداسازی داده کاربران از طریق RLS
- گردش بازبینی محتوا در تاریخچه با چهار وضعیت پیش‌نویس، در انتظار بازبینی، تأییدشده برای انتشار و نیازمند اصلاح؛ فیلتر وضعیت و ثبت زمان آخرین تغییر و یادداشت اصلاحات
- ویرایش، کپی، خروجی TXT/JSON، جست‌وجو، پوشه، برچسب و علاقه‌مندی
- تاریخچه نسخه‌ها، snapshot هنگام ویرایش و بازگردانی نسخه و مقایسه کنارهم نسخه قبلی با محتوای فعلی ذخیره‌شده، همراه با یادداشت حداکثر ۵۰۰ نویسه برای هر نسخه
- صفحه‌بندی تاریخچه با cursor و پشتیبان کامل تا سقف ۱۰٬۰۰۰ رکورد
- داشبورد تحلیل با بازه‌های ۷ روز، ۳۰ روز و کل تاریخچه؛ تجمیع سمت PostgreSQL
- ثبت تعداد تولیدهای موفق و مصرف منابع پردازش به تفکیک حساب و مدل
- دانش معتبر برند شامل واقعیت‌های تأییدشده، شواهد قابل اثبات، FAQ و ادعاهای ممنوع؛ ذخیره در پروفایل کاربر و استفاده در تولید
- حداکثر ۱۰ پروفایل برند مستقل برای هر حساب؛ با حفظ سازگاری با پروفایل قدیمی
- چک‌لیست ساختاری کیفیت محتوا، بررسی واژگان ترجیحی و کشف عبارت‌های ممنوع؛ این امتیاز به‌تنهایی صحت factual همه ادعاها را تضمین نمی‌کند
- تقویم محتوایی شمسی برای برنامه‌ریزی دستی؛ انتشار خودکار شبکه‌های اجتماعی در نسخه فعلی ارائه نمی‌شود
- مدیریت کمپین‌های بازاریابی: هدف، مخاطب، کانال‌ها، وضعیت، چک‌لیست شش‌مرحله‌ای اجرا و اتصال خودکار خروجی ذخیره‌شده به کمپین
- ثبت دستی بودجه، هزینه، نمایش، کلیک، سرنخ، تبدیل و درآمد کمپین؛ محاسبه CTR، CPL، CPA، نرخ تبدیل، مصرف بودجه و ROAS
- گزارش مقایسه‌ای حداکثر ۴ کمپین در یک جدول واکنش‌گرا با مقایسه وضعیت، بودجه، هزینه، درآمد و شاخص‌های عملکرد
- راهنمای شروع سریع سه‌مرحله‌ای برای حساب‌های بدون تاریخچه
- صفحه عمومی معرفی محصول و FAQ با توضیح روشن درباره پردازش داده و پردازشگرهای ثالث
- صفحه معرفی عمومی محصول با CTA ورود/ثبت‌نام، FAQ و متادیتای فارسی
- رابط فارسی، راست‌چین و واکنش‌گرا

## محدوده فعلی محصول

- اتصال و انتشار اینستاگرام در نسخه فعلی از رابط کاربری پنهان و غیرفعال است. کدهای آزمایشی backend در مخزن باقی مانده‌اند، اما قابلیت انتشار برای کاربران فعال یا پشتیبانی‌شده نیست.
- تقویم، ابزار برنامه‌ریزی دستی است و خودش محتوا را منتشر نمی‌کند.
- هیچ اتصال یا انتشار خودکار اینستاگرام/شبکه اجتماعی در رابط فعلی در دسترس نیست.
- همه امکانات فعلاً رایگان‌اند؛ درگاه پرداخت و اشتراک پولی فعال نیست. تولید تصویر به سهمیه فنی ۵ تصویر در ساعت برای هر حساب محدود است.
- ثبت مصرف AI فعال است. محدودیت‌های سرویس پردازش متصل و زیرساخت میزبانی همچنان ممکن است اعمال شوند.
- سرویس فعلی Render روی پلن Free است؛ این استقرار برای آزمایش و بازخورد اولیه مناسب‌تر از تعهد به دسترس‌پذیری تجاری ۲۴/۷ است.

## فناوری‌ها

- Next.js 16
- React 19
- TypeScript
- Node.js 24 LTS
- Supabase Auth و PostgreSQL
- API سرویس پردازش محتوای متصل

## اجرای محلی

نیازمندی‌ها: Node.js 24 و npm.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

برنامه در `http://localhost:3000` اجرا می‌شود.

برای بازیابی رمز عبور، دامنه Production را در Supabase Authentication → URL Configuration → Redirect URLs مجاز کن. پیش از عرضه عمومی، SMTP اختصاصی و قابل اتکا نیز برای ایمیل تأیید و بازیابی تنظیم شود.

## متغیرهای محیطی

مقادیر واقعی را فقط در فایل محلی نادیده‌گرفته‌شده توسط Git و تنظیمات امن Render وارد کن. هیچ کلیدی را در GitHub یا کد سمت مرورگر قرار نده.

| متغیر | کاربرد |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | آدرس پروژه Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | کلید عمومی anon/publishable برای کلاینت Supabase؛ امنیت داده باید با RLS تضمین شود |
| `CONTENT_GENERATION_API_KEY` | کلید محرمانه سرویس پردازش محتوای متصل برای تولید واقعی |
| `CONTENT_GENERATION_MODEL` | شناسه مدل اصلی پیکربندی‌شده |
| `CONTENT_GENERATION_FALLBACK_MODEL` | شناسه مدل جایگزین پیکربندی‌شده |
| `INSTAGRAM_APP_ID` / `INSTAGRAM_APP_SECRET` | اطلاعات محرمانه/شناسه Meta App برای Instagram Login |
| `INSTAGRAM_REDIRECT_URI` | مسیر callback ثبت‌شده در Meta |
| `INSTAGRAM_TOKEN_ENCRYPTION_KEY` | کلید Base64 سی‌ودو بایتی برای رمزنگاری توکن‌ها |
| `INSTAGRAM_GRAPH_API_VERSION` | نسخه Graph API (فعلاً v26.0) |
| `INSTAGRAM_SCHEDULER_ENABLED` | فعال‌سازی زمان‌بندی؛ فقط پس از تنظیم Vault و cron روی true قرار گیرد |

در توسعه محلی، اگر کلید محرمانه سرویس پردازش تنظیم نشده باشد، API خروجی نمونه (demo) می‌دهد و این خروجی تولید واقعی مدل نیست. در محیط Production بدون کلید محرمانه سرویس پردازش، API با خطای 503 متوقف می‌شود و خروجی نمونه به‌جای تولید واقعی نمایش داده نمی‌شود. سهمیه و محدودیت‌های پردازش تابع تنظیمات سرویس متصل است.

## ساختار اصلی

```text
app/
  api/generate/route.ts   # API سمت سرور، احراز هویت، اعتبارسنجی و تولید
  api/health/route.ts     # health check ساده برای میزبان
  api/integrations/instagram/ # OAuth، وضعیت، انتشار و زمان‌بندی Instagram
  integrations/instagram/callback/ # صفحه بازگشت OAuth
  globals.css             # طراحی و واکنش‌گرایی
  layout.tsx              # metadata، زبان فارسی و RTL
  page.tsx                # رابط اصلی
components/
  campaign-manager.tsx       # مدیریت کمپین و اتصال محتواهای ذخیره‌شده
  instagram-integration.tsx  # اتصال و انتشار مستقیم/زمان‌بندی‌شده اینستاگرام
lib/
  supabase.ts             # کلاینت Supabase
  server-controls.mjs     # اعتبارسنجی، محدودیت بدنه و rate limit
  content-quality.mjs     # تحلیل ساختاری کیفیت محتوا
  instagram-security.mjs  # رمزنگاری توکن و اعتبارسنجی OAuth
  instagram-publishing.mjs # اعتبارسنجی مسیر رسانه و زمان‌بندی
tests/                    # تست‌های خودکار
supabase/
  functions/instagram-publish-scheduler/index.ts # worker انتشار زمان‌بندی‌شده
  migrations/             # migrationهای نسخه‌دار پایگاه داده
docs/
  ROADMAP.md              # نقشه راه و وضعیت تحویل
  INSTAGRAM_SETUP.md      # راهنمای راه‌اندازی Meta App و اتصال Instagram
.github/workflows/ci.yml  # کنترل کیفیت در Pull Request و main
```

## کنترل کیفیت

```bash
npm ci
npm audit --omit=dev
npm test
npm run typecheck
npm run build
```

GitHub Actions همین کنترل‌ها را برای Pull Request به `main` و push به `main` اجرا می‌کند. آزمون smoke جداگانه نیز به‌صورت زمان‌بندی‌شده سلامت دو دامنه Production، CTA، دارایی‌های JavaScript و پنهان‌بودن رابط قدیمی اینستاگرام را بررسی می‌کند. مقادیر Supabase در CI placeholder هستند و به داده واقعی دسترسی ندارند.

## امنیت و عملیات

- جدول‌های داده کاربر با RLS و سیاست‌های مالکیت‌محور محافظت می‌شوند.
- کلید سرویس پردازش فقط باید در محیط سرور نگهداری شود.
- هدرهای پایه امنیتی HTTP شامل HSTS، nosniff، منع iframe، Referrer Policy و Permissions Policy فعال‌اند.
- پروفایل برند در user metadata همان حساب Supabase ذخیره می‌شود؛ این داده مبنای مجوز دسترسی نیست.
- rate limit تولید در PostgreSQL ذخیره می‌شود و بین restart و چند instance مشترک است.
- خروجی AI باید پیش از انتشار توسط کاربر بازبینی شود.
- محافظت Supabase Auth در برابر رمزهای افشاشده هنوز در تنظیمات پروژه فعال نشده است.
- پیش از عرضه عمومی گسترده، تست مرورگر/یکپارچه، پایش خطا، بررسی بازیابی پشتیبان و بازبینی نهایی امنیت و ظرفیت لازم است.

## وضعیت تولید تصویر

استودیوی رسانه از مدل تصویر متصل با خروجی 1K استفاده می‌کند. فایل‌ها در bucket خصوصی `generated-media` ذخیره می‌شوند و برای نمایش، لینک امضاشده یک‌ساعته صادر می‌شود. هر حساب حداکثر پنج درخواست در ساعت دارد. تولید تصویر از هزینه و سهمیه سرویس تصویر مصرف می‌کند؛ کاربر باید هر بار آن را صریحاً آغاز کند. متن فارسی هر اسلاید در رابط قابل ویرایش است و خروجی PNG با ابعاد 1080×1350 و متن روی تصویر به‌صورت جداگانه دانلود می‌شود؛ فایل اصلی بدون متن نیز در کتابخانه خصوصی باقی می‌ماند.

## وضعیت اینستاگرام

اتصال و انتشار اینستاگرام در نسخه فعلی غیرفعال است و در داشبورد نمایش داده نمی‌شود. راهنمای قدیمی در [docs/INSTAGRAM_SETUP.md](docs/INSTAGRAM_SETUP.md) صرفاً مرجع فنی آرشیوی است و مراحل آن را تا فعال‌سازی رسمی اجرا نکن.
